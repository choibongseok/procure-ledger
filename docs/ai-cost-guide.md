# AI 비용 배부 가이드

회사가 쓴 AI 비용을 부서별로 나누고, 월 마감 때 회계 전표 초안으로 넘기는 방법이다. 기능 명세는 해당 기능 명세. 화면은 "AI 비용"(`/admin/ai-cost`, 재무·관리자·감사)과 "우리 부서 AI 비용"(`/ai-cost/my`, 팀장 이상)이다.

## 한 달 흐름

1. **환율 입력**: 그 달의 1달러당 원화 환율을 정한다(재무). 확정한 달은 바꿀 수 없다.
2. **실제 청구액 입력(선택)**: 공급자 청구서와 집계가 다르면 공급자별 청구액을 입력한다. 입력하면 그 공급자의 모든 호출 금액이 청구액에 맞춰 비례로 보정된다. 비율이 0.5~2.0 밖이면 입력 오류가 아닌지 확인하라는 경고가 뜬다.
3. **배부 규칙**: 부서가 없는 호출(배치·API·시스템)과 평가 실행처럼 특정 부서의 일이 아닌 비용을 어떻게 나눌지 정한다. 처음에는 "기본 규칙 만들기"로 시작한다(평가 실행은 사용량 비율, 부서 없는 호출은 인원 비율). 규칙은 버전으로 관리하고 한 번 저장한 버전은 고칠 수 없다. 고치려면 새 버전으로 저장한다. 저장한 규칙은 적용 시작 월부터 쓰이고, 이미 확정한 달의 결과는 바뀌지 않는다.
4. **미리보기**: 월·법인·규칙 버전을 골라 부서별 부담액을 본다. 다른 버전과 비교하면 부서별 증감이 나온다. 저장하지 않으니 마음껏 바꿔 본다. 막는 문제(환율 없음, 부서 없는 호출을 받을 풀이 없음, 나눌 대상이 없음)가 있으면 확정 단추가 눌리지 않는다.
5. **확정**: 끝난 달만 확정할 수 있다(재무, 전표 입력 권한 필요). 확정하면 부서별 비용 전표 초안이 한 번에 만들어진다. 전표 초안은 승인 절차를 일반 전표와 똑같이 거친다. **확정한 사람은 그 전표를 승인할 수 없다**(기본 차단. 재무 담당이 한 명뿐인 회사는 권한 분리 규칙 화면에서 경고로 낮추고 사유 예외를 쓴다). 규칙을 저장한 사람이 확정하는 것은 기본이 경고다.
6. **틀렸을 때**: 확정 해제를 요청한다(사유 필수). **요청한 사람이 아닌 다른 재무 담당이 확인해야** 해제되고, 해제하면 임시 전표가 취소된다. 전표가 승인 요청 중이면 먼저 승인 요청을 회수하고, 승인된 전표가 있으면 먼저 역분개한다. 요청은 7일이 지나면 만료된다. 해제한 달은 다시 계산하고 다시 확정할 수 있다. 전표만 취소됐다면 "전표 다시 만들기"로 같은 줄을 다시 만든다.

## 금액이 정해지는 방식

- 금액의 원본은 호출 당시 공급자 단가로 기록된 비용이다. 가격을 나중에 바꿔도 지난 호출은 변하지 않는다. 단가가 0 인 공급자(시험용 등)는 금액이 0 으로 쌓이고 경고가 뜬다.
- 직접 비용은 호출한 사람의 **요청 시점 부서**에 붙는다. 월중에 전보해도 이미 쓴 호출은 옮겨지지 않는다. 인원 비율 기준의 인원만 월말 기준 소속으로 센다.
- 실패·차단된 호출은 금액에 넣지 않고 건수로만 보인다.
- 원 단위 나머지는 소수부가 큰 부서부터 1원씩 더해(동률은 부서 번호 순) 부서별 합이 언제나 총액과 같다.

## 법인이 둘 이상일 때

- 모든 집계·규칙 적용·확정·예산이 법인별이다. 현재 법인(또는 권한 범위)의 값만 보인다.
- 공급자 설정은 설치 전체 하나라 법인 간에 공용이다. 풀의 범위를 **법인 간 공용**으로 하면 설치 전체의 해당 비용을 법인에 먼저 나누고(인원 비율은 법인의 월말 전체 인원, 사용량 비율은 법인의 직접 비용, 고정 비율은 법인을 직접 지정), 각 법인 안에서 부서에 인원·사용량 비율로 다시 나눈다. 법인 몫의 합은 풀 금액과 같다.
- 지급은 기본 법인이 하므로, 기본 법인이 아닌 법인의 몫은 "법인 간 거래"로 **표시만** 한다(전표 메모와 실행 정보에 지급 법인이 적힌다). 상계 전표나 연결 조정은 만들지 않는다.
- 법인이 하나뿐인 설치에서는 이 선택이 보이지 않고, 규칙에 법인 간 풀이 있어도 법인 안 풀로 처리한다.

## 예산과 알림

- 부서별 월 AI 비용 예산은 구매 예산과 별개다(`/admin/ai-cost/budgets`). 사용액은 부서가 직접 쓴 비용이다.
- 사용액이 예산의 80%와 100% 에 닿으면 부서장과 재무 담당에게 알림이 한 번씩 간다(같은 달·부서·문턱 중복 없음). 그 달 환율이 없으면 가까운 이전 달 환율로 어림하고 화면에 표시한다.
- 팀장은 "우리 부서 AI 비용"에서 12개월 추이, 이번 달 예상, 용도별 사용, 예산 대비를 본다. 프롬프트와 답변 내용은 어디에도 보이지 않는다.

## 설정

- **비용 계정**: 확정이 만드는 전표의 차변 계정이다. 기본은 5290 기타비용이고, 규칙 화면의 "비용 전표의 비용 계정"에서 사용 중인 비용 계정으로 바꾼다(재무). 이미 만든 전표는 그대로이고 다음 확정부터 적용된다. 대변은 미지급금이다.
- **권한**: `cost:read`(관리자·재무·감사)는 법인 범위 안의 전사 조회, `cost:allocate`(재무만)는 환율·청구액·규칙·예산·확정·해제·설정이다. 해제 요청·확인·반려는 비밀번호·2단계 로그인을 거친 웹 세션에서만 된다(API·개인 토큰은 안 된다).
- **AI 연결(MCP)**: `get_ai_cost_summary` 도구가 부서의 월 AI 비용 숫자(호출 수·금액, 용도별)만 돌려준다. 기본은 본인 부서이고 다른 부서는 AI 비용 조회 권한과 법인 범위가 필요하다. 규칙·환율·확정은 도구로 할 수 없다.

## 도입 점검표

"도입 점검"의 "AI 비용 배부" 항목(해당 없음 선택 가능)은 규칙·월 환율·확정한 달이 모두 있으면 완료, 일부만 있으면 진행 중이다. 시작할 때는 공급자 단가 설정 확인 → 지난 달 환율 입력 → 기본 규칙 → 미리보기 확인 → 확정 순서로 진행한다.

## 자주 묻는 일

- **확정이 안 눌려요.** 미리보기 위쪽의 오류 문구를 읽는다. 대부분 환율이 없거나, 부서가 없는 호출을 받을 풀이 없거나, 이번 달이다(끝난 달만 확정된다).
- **"이 달 장부가 마감되어 전표를 만들 수 없습니다"**: 장부(재고 월 마감 포함) 마감을 해제한 뒤 다시 확정한다. 확정은 통째로 취소되어 아무것도 남지 않는다.
- **전표가 승인됐는데 틀렸어요.** 전표를 역분개한 뒤 확정 해제를 요청한다.
- **CSV**: 확정한 달은 확정 결과, 아니면 미리보기가 상태 칸과 함께 내려간다. 사용자 이름은 들어 있지 않다.

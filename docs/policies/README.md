# 사내 규정 문서

이 폴더의 `*.md` 가 규정 검색(B12)의 원본이다. 서버가 기동할 때 읽어 조항 단위로 색인한다.

형식
- 맨 위 머리말(`---` 으로 감쌈)에 `title`, `roles`, `departments` 를 둔다.
- 조항은 `## 제N조 (제목)` 줄로 시작한다. 조항 앞의 글은 색인하지 않는다.
- `roles`: 볼 수 있는 역할(admin, finance, manager, staff, auditor 를 쉼표로). `all` 은 전 역할.
- `departments`: 볼 수 있는 부서 이름(쉼표로). `all` 은 전 부서.
- 열람은 두 조건을 모두 만족해야 한다(역할 AND 부서). 머리말이 없거나 형식이 틀린 문서는 아무에게도 보이지 않는다.

이 README 는 규정이 아니므로 색인하지 않는다.

# 감사 및 개인정보 보호 규정

## 제1조 (감사 로그)
누가, 언제, 무엇을, 어떤 경로(웹, MCP, 게이트웨이)로 했는지를 감사 로그에 남긴다. 로그는 추가만 가능하며 이전 기록의 해시를 포함해 변조를 검출한다. 기록에 실패하면 요청 자체가 실패한다.

## 제2조 (감사 조회와 체인 검증)
감사 담당자는 감사 로그를 조회하고 해시 체인을 검증할 수 있다. 외부 앵커 파일과 대조해 꼬리 삭제나 전체 재계산도 잡는다.

## 제3조 (민감 정보 마스킹)
사업자번호, 계좌번호, 연락처, 이메일은 역할에 따라 응답에서 가려진다. 원문 조회 권한은 관리자와 재무에만 있다. AI로 나가는 텍스트는 전송 전에 항상 마스킹한다.

## 제4조 (개인 토큰)
MCP와 API 는 사용자가 발급한 개인 토큰으로 접근한다. 토큰은 해시로만 저장하며 만료와 폐기가 가능하다. 토큰으로 호출해도 웹과 같은 권한 표가 적용된다.

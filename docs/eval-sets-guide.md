# 회사 평가 세트 운영 가이드

모델·라우팅·프롬프트를 바꿀 때 "우리 회사 업무에서 품질이 떨어지지 않았는지"를 같은 문항으로 확인하는 방법이다. 명세는 해당 기능 명세.

## 1. 세트 만들기

1. 관리자 메뉴 "평가 세트"에서 새 세트를 만든다(코드·이름·용도). 용도는 증빙 문서 판정·규정 검색·도구 선택·일반 질의 중 하나다.
2. 문항을 하나씩 더하거나 CSV 로 가져온다. CSV 머리글은 `문항,기대,채점,허용오차,치명,태그,맥락,기준` 이고 UTF-8(BOM 허용)이다. 한 행이라도 틀리면 전부 취소되고 어느 행·열인지만 알려 준다.
3. 채점 기준은 가능하면 정확 일치·포함·숫자(허용 오차)를 쓴다. LLM 채점은 CI 에서 `필수:`·`금지:` 줄만 보는 결정적 모의 채점기로 돈다.
4. 문항의 사업자번호·계좌·연락처는 저장 전에 가려진다. 가려진 값으로는 기대 답이 맞을 수 없으므로 개인정보 값 자체를 묻는 문항은 만들 수 없다.
5. 게시하면 그 버전은 고칠 수 없다. 고치려면 "새 초안"에서 고쳐 다시 게시한다. 문항은 수십 개면 충분하고 자주 보강한다. **세트를 프롬프트나 일반 사용자에게 보여 주지 않는다**(모델이 기대 답을 외우면 평가가 의미 없어진다).

## 2. 실행과 비교

- 세트 상세의 "실행과 결과"에서 공급자(등록된 것 또는 현재 경로)와 모델을 골라 실행한다. 외부 공급자는 비용이 들고 일일 한도(`eval.run` 용도)를 쓴다. 비용 확인을 체크해야 시작된다.
- 결과는 합격률·실패 문항(문항·기대·사유 한 줄)·치명 실패·지연(합·평균·p95)·토큰·비용이다. 응답 전문은 저장하지 않는다. 치명 문항이 하나라도 틀리면 합격률과 상관없이 기준 미달이다.
- 같은 세트의 두 실행을 비교하면 같은 버전일 때 문항별로 회귀(기준에서 통과 → 실패)·개선을 보여 준다. 버전이 다르면 합계만 비교한다.
- 명령줄: `go run ./cmd/eval --set <코드>[@버전] --provider mock --db <파일>`. 종료 코드는 0 합격, 1 기준 미달, 2 설정 오류.

## 3. 기준선과 알림

- 믿을 만한 실행 하나를 "기준선으로 지정"한다(끝난 실행만, 다른 버전이면 경고). 세트마다 허용 하락(기본 2%p)이 있다.
- 새 실행이 기준선보다 허용 하락을 넘게 낮거나 치명 실패가 있으면 결과 화면에 경고가 뜨고, 평가 세트 관리 권한(`eval:write`)을 가진 사람과 실행한 사람에게 앱 안 알림이 간다.

## 4. 저장 전 평가(라우팅 게이트)

1. 세트 상세의 "저장 전 평가"에서 용도 패턴(예: `docverify.*`)에 이 세트를 지정하고 켠다. 지정이 없으면 게이트는 걸리지 않는다.
2. LLM 라우팅 규칙을 저장하면 서버가 그 용도와 겹치는 지정 세트의 앞 20문항을 **후보 경로(주 공급자·모델)** 로 60초 안에 돌려 기준선과 견준다. 순서·시도 횟수만 고치는 저장, 꺼진 규칙 저장은 평가하지 않는다.
3. 기준선보다 허용 하락 넘게 낮거나 치명 문항이 틀리면 저장하지 않고 "기준선(○○%)보다 낮습니다(△△%, 치명 실패 N건). 그래도 저장하시겠습니까?" 를 보인다. 사유(선택)를 적고 "그래도 저장"하면 저장되고 감사 로그에 `평가 게이트 무시하고 저장`(세트·후보 점수·기준선 점수·치명 실패 수·사유 입력 여부, 사유 내용은 없음)이 남는다.
4. 외부 공급자 후보는 평가 비용이 들므로 먼저 "비용을 확인하고 평가 실행" 확인을 받는다.
5. 평가를 못 돌리면(기준선 없음, 세트 꺼짐, 시간 초과, 후보 공급자 오류, 리허설 중 외부 후보) 저장은 막히지 않고 "저장 전 평가를 건너뛰었습니다: 사유" 가 보인다.
6. 프롬프트 저장 전 평가는 같은 함수(`evalset.Service.CheckGate`)를 부르면 된다. 프롬프트 편집 기능이 없어 지금은 호출 지점이 없다.

## 5. 점검

- 도입 점검표의 "평가 세트" 항목: 게시된 세트가 있으면 완료.
- `make verify` 는 mock 기본 골든셋만 돈다. 회사 세트는 `go test`·e2e(시험 세트를 만들어 mock 으로 실행)로 확인한다.
